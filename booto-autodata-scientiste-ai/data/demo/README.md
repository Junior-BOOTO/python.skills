# Données entièrement synthétiques

Les CSV de ce dossier sont des scénarios fictifs générés par `src/autodata/demo.py`. Il ne s'agit pas d'un échantillon représentatif du monde réel. Aucune information de personne n'y figure.

- `classification_synthetique.csv` : 180 lignes, cible `categorie_fictive`.
- `regression_synthetique.csv` : 180 lignes, cible `montant_simule`.

Les métriques qui en découlent ne démontrent ni la qualité d'un modèle en production ni un effet causal.
