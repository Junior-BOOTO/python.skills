# FLE Resource Studio — Junior BOOTO Waba

## Une ressource, trois chemins pour apprendre

Un studio Python pour préparer des fiches FLE A1 cohérentes : objectif commun, lexique, phrase modèle, aides graduées et critères observables. Son apport est l'assemblage explicite de ressources pédagogiques inspectables, relié à un catalogue et une API locale.

Cinq thèmes : meubles, routine, travaux ménagers, paysages et droits/devoirs avec écoresponsabilité. Cinquante entrées de glossaire FR/ES/EN ; trois aides et trois langues produisent 45 combinaisons vérifiées. Cinq kits par défaut sont livrés.

## Parcours utilisateur

Choisir le thème → choisir l'aide → afficher les modèles et le glossaire → préparer les trois phrases → observer les critères « Je peux… ». L'objectif reste commun et les appuis varient.

Le studio dispose d'une exportation JSON et d'une feuille d'impression apprenant. La lecture vocale est facultative et dépend des voix françaises du navigateur ; aucun fichier audio enregistré n'est livré. Les vidéos candidates restent hors des ressources approuvées jusqu'à la revue explicite d'un enseignant.

## Preuves techniques

20 tests réussis localement, incluant les 45 combinaisons, les options interdites, la cohérence du corrigé, la distinction vidéo candidate/approuvée et l'API locale. JavaScript : syntaxe vérifiée. Interface visuelle, impression et lecture vocale : à vérifier en navigateur. Connecteur YouTube fourni, testé avec réponses simulées, sans appel authentifié réel.

Les ressources sont proposées, non expérimentées en classe dans cette livraison. Aucune efficacité pédagogique ni maîtrise CECRL n'est attribuée automatiquement.

## English summary

FLE Resource Studio is a Python MVP combining an explicit A1 pedagogical catalog, trilingual glossary, differentiated resource kits and a local read-only API. Five themes, fifty glossary entries and forty-five supported configurations are included. Twenty behavior tests pass locally. Browser speech is optional; video metadata does not imply teacher approval. Teacher review remains necessary.
