# FLE Resource Studio 1.0.1

Première distribution versionnée du prototype FLE × Python de Junior BOOTO Waba.

## Téléchargements
- fle-resource-studio-1.0.1.zip : code, catalogue, studio HTML autonome, cinq kits, tests et guide DEMARRAGE.md.
- SHA256SUMS.txt : empreinte de l’archive produite.
- release-validation.json : liste des fichiers et résultats des contrôles exécutés sur l’archive extraite.

## Parcours rapide
Extraire le ZIP puis ouvrir reports/studio.html. Python est facultatif pour consulter les supports ; Python 3.10+ est requis pour les reconstruire. Voir DEMARRAGE.md pour les commandes.

## Portée de la validation
La publication exige que la suite de tests passe sous Python 3.10 et 3.12. Le ZIP est construit et contrôlé sous Python 3.12, avec une nouvelle exécution des tests et des commandes de génération depuis une extraction temporaire.

La synthèse vocale réelle, l’impression et le rendu visuel restent à vérifier sur votre appareil. Aucun résultat d’apprentissage mesuré, aucun MP3 et aucune photographie réaliste ne sont annoncés. Les ressources nécessitent une revue enseignante.
