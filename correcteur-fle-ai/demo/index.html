À quoi sert cette V1 ?

Cette démonstration repère seulement certains modèles de difficultés ciblées (pronoms réfléchis, conjugaisons, accents, accord du pluriel). La version Python constitue la référence fonctionnelle du projet ; cette page HTML réimplémente un sous-ensemble pédagogique des règles. Elle ne stocke aucune réponse dans une base de données et n'utilise pas d'API externe.
