Prototype A1 — propositions validées par l'enseignant

TEXTE INITIAL
je doit protege les arbre. nous doit recycler les dechets.

TEXTE RÉVISÉ
je dois protéger les arbres. nous devons recycler les déchets.

PISTES RETENUES
• je doit protege → je dois protéger (Conjugaison et infinitif) : Avec « je », on dit « je dois » ; après « devoir », on emploie l’infinitif « protéger ».
• les arbre → les arbres (Accord nominal) : Après « les », le nom « arbres » prend un « s » au pluriel.
• nous doit → nous devons (Conjugaison) : Avec « nous », on dit « nous devons ».
• les dechets → les déchets (Accents) : Le mot « déchets » comporte deux accents aigus.
