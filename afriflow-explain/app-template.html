Une comparaison à budget égal

Deux Isolation Forest de configuration identique : le premier utilise des résumés de montants et du nombre d’opérations ; le second ajoute les liens temporels, les degrés et la structure du réseau. Les 36 dossiers aux scores les plus élevés sont retenus dans chaque méthode. Aucun label ne sert à l’entraînement.

Même si les parcours améliorent ce test, les faux positifs restent nombreux. Les scénarios et les réseaux sont artificiels : ce résultat n’est pas une performance démontrée sur une banque africaine.

Trois rôles, un dossier partagé

01 · DataCollect

Préserver la source, vérifier les identifiants, dates et devises, signaler les horodatages absents.

02 · DataAnalyse

Construire les composantes par fenêtre et devise, vérifier les parcours et produire leurs preuves.

03 · DataML

Comparer les priorisations sur une période indépendante, exporter modèles et résultats.

Les rôles s’enchaînent dans le pipeline Python. Aucun appel automatique aux trois GPTs indépendants n’a été réalisé.

Reproduire et examiner les limites

python -m pip install -r requirements.txt
python pipeline.py
python build_demo.py
python -m unittest discover -s tests -v

Analyse rétrospective à fermeture de fenêtres UTC de 24 heures, pas détection en direct. Les institutions sont fictives ; les devises ne sont jamais additionnées entre elles. Les modèles ne reçoivent ni pays, ni identifiants, ni scénario de simulation.

Le générateur crée des groupes de comptes disjoints, plus faciles à isoler que des réseaux bancaires réels. Les composantes calculées retrouvent donc des scénarios artificiellement séparés. Les explications sont des motifs observés et non des attributions causales du score Isolation Forest.
