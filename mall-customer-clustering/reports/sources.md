# Provenance, accès et transformations

Fiche : **Vijay Choudhary, Mall Customer Segmentation Data**, https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python.

La fiche présente un jeu créé pour apprendre les concepts de segmentation et cite le cours Udemy Machine Learning A-Z. Elle renvoie au dépôt `SteffiPeTaffy/machineLearningAZ`, utilisé ici comme source d’accès du CSV, sans le présenter comme une collecte indépendante vérifiée.

Commit, chemin, URL exacte et empreinte Git du CSV sont fixés dans `source.json`. Le SHA-256 du fichier utilisé est dans `manifest.json`. Collecte et analyse : 11 octobre 2026, heure de Bogotá.

La licence de la fiche indique « Other (specified in description) » ; une permission explicite de redistribution du CSV n’a pas été identifiée. Le CSV brut et les affectations individuelles ne sont donc pas inclus dans le dépôt ou l’archive. Le script de récupération, le code et les résultats dérivés sont fournis.

La période, le pays, les modalités de collecte et la formule du score sont inconnus. Il s’agit d’un jeu pédagogique ; l’authenticité comme données opérationnelles de clients n’est pas établie.

Transformations : identifiants préservés comme chaînes, aucune imputation ou suppression de profil. Deux variables standardisées pour l’analyse primaire ; l’identifiant et le genre sont exclus, et l’âge est ajouté seulement pour la sensibilité. Standardisation réajustée dans chaque sous-échantillon. Les CSV sources restent intacts.

Inspiration du projet : *Data Analysis Projects*, Natacha Njongwa Yepnga / LeCoinStat, projet 9. Le PDF original n’est pas redistribué.
