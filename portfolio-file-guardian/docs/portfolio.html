Le problème

Les ressources d'un portfolio sont dispersées et parfois répétées. Un nom identique ne prouve pas un contenu identique.

Guardian crée un inventaire, compare les empreintes et propose des catégories configurables.

La démarche

La simulation est le comportement par défaut. La copie explicite utilise un nouveau dossier, vérifie les octets et conserve un journal.

La restauration retire seulement les copies journalisées et inchangées.

Compétences et limites

Python modulaire, CLI, lecture en flux, SHA-256, exports JSON/CSV/HTML, validation des chemins et tests isolés. Aucune dépendance tierce d'exécution.

Prototype pour des dossiers locaux stables : pas de synchronisation cloud, de déduplication destructive ou de transaction globale après panne. Validation exécutée sous Linux ; GitHub Actions fourni mais non exécuté sur GitHub.

Projet réalisé avec assistance IA pour le portfolio de Junior BOOTO Waba, inspiré des exercices de gestion de fichiers de 53 Must Do Python Projects For All. Implémentation originale ; aucun code du livre redistribué.
